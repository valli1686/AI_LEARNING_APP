# 📚 StudyHub – AI Learning Assistant

StudyHub is a full-stack AI-powered learning platform that helps students learn more effectively from their study materials. Users can upload PDF textbooks, notes, and research papers to automatically generate flashcards, practice quizzes, study summaries, and contextual question-answering experiences.

## Key Features

### 📄 Smart Document Management

* PDF upload and processing
* Intelligent text extraction and chunking
* Organized document library

### 🎴 AI Flashcards

* Automatic flashcard generation
* Difficulty-based learning
* Review tracking and favorites

### 🧠 AI Quiz Generator

* Multiple-choice practice quizzes
* Instant explanations
* Performance analytics

### 📝 Study Summaries

* Executive overview
* Key concepts
* Important takeaways
* Structured revision notes

### 💬 Document-Based AI Tutor

* Ask questions about uploaded documents
* Context-aware responses
* Grounded answers from study material

### 📊 Analytics Dashboard

* Study streak tracking
* Quiz performance monitoring
* Flashcard progress metrics
* Learning insights
